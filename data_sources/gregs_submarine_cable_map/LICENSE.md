# Ambiguous upstream license notice

The ArcGIS item states only:

> GNU GENERAL PUBLIC LICENSE

No version is specified. The artifact records this literally as **“GNU GPL, version unspecified”**
and makes no SPDX-version claim. The applicability and version of GNU GPL terms for these data are
ambiguous. Users and redistributors must evaluate that ambiguity and preserve this warning.

Attribute Greg Mahlknecht / Greg's Global Submarine Cable Map. The artifact is modified: stations
are matched to route vertices, graph topology is derived, identifiers and schemas are normalized,
parallel routes are combined, and geodesic route distances in metres are calculated.
