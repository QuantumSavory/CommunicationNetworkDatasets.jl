# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). This project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) after its first package release.

## v0.1.1 - 2026-08-21

- Publish two AfTerFibre and two PDOK water-authority networks, bringing the catalog to 11 datasets
  and 1,014 semantic networks.
- Preserve AfTerFibre's implied GPL 2.0 scope warning and PDOK's conflicting CC0 and CC BY-NC-ND
  4.0 notices, with the requested non-derivative publication position.
- Refresh and pin the PDOK extractor to the 2026-08-20 ATOM GML snapshot.

## v0.1.0 - 2026-08-09

- Initial package API, artifact schema, source extractors, plotting extension, documentation, and
  automation.
